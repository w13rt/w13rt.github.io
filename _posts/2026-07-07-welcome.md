## Writing posts

Posts live in `_posts/` and follow the naming convention
`YYYY-MM-DD-title.md`. Each post starts with front matter:

```yaml
---
layout: post
title: "My post title"
subtitle: "Optional subtitle"
tags: [topic-one, topic-two]
---
```

## Formatting

All the usual Markdown works. **Bold**, *italic*, `inline code`, and
[links](https://jekyllrb.com).

> Blockquotes look like this — good for pull quotes or asides.

Code blocks get syntax highlighting:

```python
def greet(name):
    """Say hello."""
    return f"Hello, {name}!"
```
